# 梦回·群星录

## 局域网启动

在 Windows PowerShell 中运行：

```powershell
./start-lan.ps1
```

脚本会输出一个 `http://192.168.x.x:4174` 或 `http://10.x.x.x:4174` 地址。连接到同一 Wi-Fi 或同一局域网的电脑、手机可直接用浏览器打开该地址，不需要 VPN。

`127.0.0.1:4174` 只允许运行服务的这台电脑访问，不能发给朋友。

## 国内 BaaS 部署建议

当前页面已移除境外静态资源。要让中国各地朋友异地访问且不租传统服务器，可以使用腾讯云 CloudBase：创建免费环境和云托管服务，将本目录部署为 Node 云托管服务，再把房间数据迁移到 CloudBase 数据库集合 `rooms`。配置示例见 `cloudbase-config.example.json`。

CloudBase 的环境 ID、账号权限和发布操作必须由项目拥有者在腾讯云控制台完成，不能把密钥写进前端。完成云托管后，将游戏访问地址指向云托管域名即可，游戏流程不需要改变。

## 外网多人访问

异地朋友无法通过局域网地址连接。需要将该 Node 服务部署到一台具有公网 IP 的中国大陆云服务器，或通过合规的内网穿透/反向代理提供 HTTPS 域名。要稳定支持几十名同时在线玩家，建议使用至少 1 核 2 GB 内存的服务器，并将房间数据迁移到 Redis 或数据库；当前版本的房间数据存在进程内存中，重启服务会清空。
